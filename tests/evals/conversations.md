# Skill 对话验收场景

在目标 Agent 宿主加载当前 Skill 后，分别开启新会话执行以下场景。保存逐轮回复、脚本输入/输出和最后链接。此文件是验收用例，不代表已通过模型或平台实测。

| 场景 | 用户输入/后续输入 | 验收条件 |
|---|---|---|
| 明确需求 | 用田字格练“春夏秋冬”，带拼音 | 不追问年龄；原文完整；grid_type=tian、pinyin=true；真实执行脚本 |
| 模糊起点 | 孩子不知道练什么 | 一次只问一个影响推荐的问题；获得学习阶段后给具体字组或练习，不反问模板编号 |
